# VaR / CVaR 金融风险度量模型

基于 A 股真实数据，用三种方法（历史模拟法、参数法、GARCH 模型）计算在险价值（VaR）和条件在险价值（CVaR），并通过 Kupiec 检验进行回测验证。

## 项目概览

覆盖金融风险度量的完整链条：**数据获取 → 探索性分析 → 建模估计 → 回测验证**。

选取四个不同风格的 A 股标的（上证指数、创业板指、招商银行、贵州茅台），在 2021~2026 年的日线上对比三种 VaR 方法的表现。

## 三种 VaR 方法

### 方法一：历史模拟法（基准）
无分布假设，直接取历史收益率的经验分位数作为 VaR。简单透明，作为对比基线。

### 方法二：参数法（正态 / t 分布）
假设收益率服从已知分布，估计参数后反算 VaR。用于对比——所有标的的 JB 检验均拒绝正态假设（p≈0），峰度远高于 3，因此正态参数法会系统性高估或低估尾部风险。

### 方法三：GARCH(1,1) 动态 VaR（核心）
金融数据存在波动聚集效应（大涨大跌后波动大，平稳期波动小）。GARCH 模型捕捉条件波动率的时变性，计算动态 VaR，解决了静态方法"方差恒定"的不合理假设。

## 回测验证

使用 Kupiec 无条件覆盖检验（LR ~ χ²(1)），以 500 天滚动窗口检验 VaR 模型是否准确。

**核心结果：**

| 标的 | 方法 | 95% VaR 违反率 | p 值 | 结论 |
|------|------|:------------:|:----:|:----:|
| 上证指数 | 历史模拟法 | 3.90% | 0.1413 |  通过 |
| 上证指数 | GARCH 法 | 3.65% | 0.0678 |  通过 |
| 创业板指 | 历史模拟法 | 4.79% | 0.7805 |  通过 |
| 招商银行 | 历史模拟法 | 2.90% | 0.0033 |  保守拒绝 |
| 贵州茅台 | 历史模拟法 | 3.53% | 0.0447 |  保守拒绝 |

**关键发现：**
- 上证指数和创业板指上，历史模拟法通过了 Kupiec 检验，对于波动结构稳定的标的，简单方法表现稳健
- GARCH 法在上证指数上也通过了检验（p=0.0678），违反率 3.65% 比历史模拟法的 3.90% 更接近期望值
- 招行和茅台被拒绝的原因是违反偏少（模型高估了风险，偏保守），这在风控实务中反而是安全的方向
- 99% VaR 所有标的均通过了检验（p > 0.05）

# 3. EDA

python main.py

python validation/run_backtest.py
